# 海边来信 · 更新说明

当前目录是从用户提供的 pixel-sea-window.zip 解压后优化的完整项目。原始压缩包未修改。

## 第二版：静静的窗帘与声景

- 窗帘减小风力与鼠标作用力，增加阻尼和回位；水平方向限制在初始位置 ±2 个内部像素，竖直方向 ±0.6 像素。慢动效下水平限制 ±0.7 像素。
- 海浪默认峰值增益从原先 0.32 降至 0.12，风铃音符峰值保持 0.045。此为信号增益，不等于主观响度比例。
- 猫咪新增短喵、长喵、双声三种合成声音，连续两次不同，快速点击有 0.85 秒间隔。
- 细雨模式自动淡入滤波雨声，晴天淡出；都服从声音总开关。
- 「声景」可选三首原创合成循环旋律：岸边慢信（62 BPM）、云朵午睡（72 BPM）、月色摇篮（52 BPM），也可只听自然声。这些是程序合成曲目和拟声，不是真猫录音或商业歌曲。
- 总音量、海浪、细雨和音乐音量可分别调整，曲目与音量记忆在本地，声音始终需要手动开启。隐藏和静音时停止音乐调度，切歌会淡出旧音符。
- `npm test` 新增窗帘位移边界、三个音乐编排、雨声混音、音量限制、猫叫变化、切歌和静音清理检查。音频使用模拟 Web Audio 节点检查调度与状态，尚未完成真实设备试听。

## 体验

- 扩大海景视野，收窄两侧帘幕。修正天空渐变方向。
- 用透视波纹、长涌浪、细碎浪头、日月反射光带替换原来的重复格纹。增加远岛和海鸟。
- 点击或按住划过海面产生椭圆涟漪；掠过窗帘保留原有布料反馈。
- 点猫咪会眯眼、摇尾并浮出爱心；点盆栽浇水并短暂开花；点蜡烛开关暖光；点右侧风铃会摇摆，开启声音后有铃音。
- 晴天与细雨、真实时间与晴昼/日落/月夜自由切换。
- 自制本地海浪声默认关闭；呼吸引导为四秒吸气、六秒呼气，无倒计时任务或打卡要求。
- 增加书本、热茶、纸签风铃。底部工具栏闲置淡出，键盘聚焦时显示，问号提供互动提示。
- 设置保存在本机。声音不自动开启。30 帧上限，慢动效模式 10 帧，隐藏页面暂停绘制并淡出声音。
- Electron 顶部提供置顶和收起，托盘可找回。浏览器版自动隐藏桌面按钮。

## 打开

直接用浏览器打开 `src/index.html` 即可体验，不需要安装依赖或联网。

桌面版在项目目录运行 `npm install`，再运行 `npm start`。运行 `npm run dist` 可构建 Windows portable 应用；本次没有安装 Electron 或生成 exe。

## 验证范围

`npm test` 使用 Node 的 VM 和仪器化 Canvas 验证场景运行、昼夜/雨天组合、互动状态、涟漪回收、缩放坐标和隐藏暂停逻辑，不依赖第三方包。

这不代替视觉验收和真实音频试听。当前内置浏览器策略禁止 file URL，未进行浏览器画面验收及 Electron 实机测试。
