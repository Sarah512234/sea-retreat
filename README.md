# 像素风海景窗 · Pixel Sea Window

现已更新为「海边来信」：扩大的海景、透视海浪与日月倒影、拨水涟漪、细雨、浇花、摸猫、风铃、可选海浪声和呼吸引导。完整说明与验证范围见 [更新说明](docs/retreat-update.md)。

第二版：窗帘改为低幅、快速回稳的轻微摆动；海浪默认调轻，保留风铃音量。开启「声音」后，摸猫随机播放三种合成猫叫，细雨模式自动混入雨声。「声景」面板提供三首本地合成轻音乐和总音量、海浪、雨声、音乐四个音量滑杆；关闭声音会统一静音，重新打开页面仍默认静音。

一个挂在桌面上的像素风小窗：一扇打开的玻璃窗、两侧蕾丝窗帘，窗外是随着真实时间潮起潮落的大海。

## 效果

- 像素风大海：透视长波、分层碎浪、随日月位置展开的倒影、远岛和海鸟
- 天空、太阳、月亮、星星、云都会随真实时间变化（日出日落带暖色）
- 海平面按约 12.4 小时的半日潮周期涨落，远处还有随波起伏的小帆船
- 温馨室内：暖色壁纸、木窗台、小盆栽、橘猫、夜灯蜡烛
- 墙面时钟显示真实时间（时:分:秒 + 日期），秒数闪烁
- 蕾丝窗帘：verlet 布料模拟 + 方向光照与褶皱明暗（夜晚偏冷、白天偏暖）
- 互动：拂动窗帘、拨水、摸猫、浇花、开关烛光、轻碰风铃；下方问号可查看提示

## 快速体验（无需安装）

- 双击 `summon.bat`：在屏幕右上角用 Edge 独立窗口打开（无标签栏、无地址栏）
- 如果双击 `.vbs` 变成了“打开成文本”，说明系统把 `.vbs` 关联到了编辑器，改用 `summon.bat` 即可
- 或直接用浏览器打开 `src/index.html`
- 下方「此刻」按钮可轮换晴昼、日落和月夜；在「此刻」模式下，网址末尾加 `?t=时:分` 也可预览某个时刻，例如 `src/index.html?t=22:30`

## 桌面应用（Electron，真正的独立小窗）

前置：已安装 [Node.js](https://nodejs.org/)（含 npm）。

```bash
# 1) 安装依赖（一次性，需要联网）
npm install

# 2) 本地运行：无边框、置顶、带托盘图标，点击托盘召唤/隐藏，默认在右上角弹出
npm start

# 3) 打包成独立程序（生成到 release/，portable exe，双击即用）
npm run dist
```

应用特性：窗口无边框、始终置顶、不占任务栏，可在系统托盘点击召唤/隐藏，也可以把整个窗口拖到任意位置。

窗口顶部有一条透明的拖拽区，按住它即可拖动窗口；其余区域可以正常点击互动。

## 发布成公开项目（GitHub）

直接上传压缩包中的源码并开启 GitHub Pages，请按 [GitHub 上传说明](GITHUB-START.md) 操作。项目已包含 `.github/workflows/pages.yml`：更新 `main` 分支后先测试，再发布 `src` 目录。

```bash
git init
git add .
git commit -m "像素风海景窗：初始版本"
git branch -M main
git remote add origin https://github.com/<你的用户名>/pixel-sea-window.git
git push -u origin main
```

推送前请先到 GitHub 新建一个空仓库，把上面的 `<你的用户名>` 换成你自己的账号名。
